👋 Make the page react

You already know how to build a page. Now you will make it do something when a button is clicked — change words, colours, sizes and the whole background. Work top to bottom: MUST (learn each power) → SHOULD (combine them) → COULD (write your own).

Every single change is the same two steps:
1FIND the element  document.getElementById("t")
2CHANGE it  .innerHTML · .style.color · .style.fontSize
Reading the code
orange = HTML tags
blue = JavaScript that finds & changes
green = the value you choose (in quotes)
purple = keywords like function

MUST DO

Everyone does these
3 exercises

Three superpowers. Every page change in JavaScript is the same move: FIND an element (we gave it an id, then grab it with document.getElementById), then CHANGE it. Here you meet the three changes you will use the most — the words, the colour, and the size. Read each one, type it, Run it, then do the small Your turn tweak so it becomes yours.

1

Reveal a secret message

innerHTML
The idea.innerHTML is the words inside an element. Change it and the words on the page change.
1 Read this code
<h1 id="msg">🔒 Locked</h1>
<button onclick="reveal()">Reveal</button>

<script>
  function reveal() {
    document.getElementById("msg").innerHTML = "🎉 You found me!";
  }
</script>
2 Type it here
3 Result
Your turn → Change the secret message to your own — your name, a joke, anything.
Watch out! The name in getElementById("msg") must match id="msg" on the <h1> exactly — same spelling, same capitals.
2

Mood colour

.style.color
The idea.style.color changes the text colour. The colour is a name in quotes, like "tomato" or "deepskyblue".
1 Read this code
<h1 id="t">How are you today?</h1>
<button onclick="mood()">My mood</button>

<script>
  function mood() {
    document.getElementById("t").style.color = "deeppink";
  }
</script>
2 Type it here
3 Result
Your turn → Swap "deeppink" for your own mood colour — try "gold", "teal" or "orangered".
Watch out! Colour names go in quotes. color = blue breaks; color = "blue" works.
3

Make it SHOUT

.style.fontSize
The idea.style.fontSize changes how big the text is. Bigger number, bigger text.
1 Read this code
<h1 id="t">turn me up</h1>
<button onclick="shout()">SHOUT</button>

<script>
  function shout() {
    document.getElementById("t").style.fontSize = "80px";
  }
</script>
2 Type it here
3 Result
Your turn → Try a bigger number like "120px". How big is too big to fit?
Watch out! Keep px inside the quotes: "80px" — not 80px and not "80".

SHOULD DO

Combine the powers
3 exercises

Now stack them. Real pages change more than one thing at once. Here you put two or three changes in a single function, paint the whole page, and wire up two buttons that do different jobs. Same three powers as MUST — just working together.

1

GOOOAL! celebration

text + colour + size
The ideaOne button, three changes. Stack the .innerHTML, .style.color and .style.fontSize lines inside the same function.
1 Read this code
<h1 id="t">Kick off...</h1>
<button onclick="goal()">Shoot!</button>

<script>
  function goal() {
    document.getElementById("t").innerHTML = "⚽ GOOOAL!";
    document.getElementById("t").style.color = "green";
    document.getElementById("t").style.fontSize = "75px";
  }
</script>
2 Type it here
3 Result
Your turn → Make it your team or game — change the words, the colour and the size to match.
Watch out! Each change is its own line ending in a semicolon ;. Three changes = three lines.
2

Night mode

document.body.style.background
The ideadocument.body is the whole page. .style.background paints its background colour.
1 Read this code
<h1 id="t">☀️ Day</h1>
<button onclick="night()">Night mode</button>

<script>
  function night() {
    document.body.style.background = "black";
    document.getElementById("t").innerHTML = "🌙 Night";
    document.getElementById("t").style.color = "white";
  }
</script>
2 Type it here
3 Result
Your turn → Pick your own night colours — midnight blue? dark purple? Keep the heading readable against the background.
Watch out! If the heading "vanishes", the text colour matches the background. Change one of them so they contrast.
3

Like or Nah

two functions
The ideaTwo buttons, two jobs. Each button calls its own function through its own onclick.
1 Read this code
<h1 id="t">Rate this lesson</h1>
<button onclick="like()">👍 Like</button>
<button onclick="nah()">👎 Nah</button>

<script>
  function like() {
    document.getElementById("t").innerHTML = "Thanks! 🙌";
    document.getElementById("t").style.color = "green";
  }
  function nah() {
    document.getElementById("t").innerHTML = "Fair enough 😅";
    document.getElementById("t").style.color = "crimson";
  }
</script>
2 Type it here
3 Result
Your turn → Add a third button and function — maybe "🤔 Not sure" that turns the text orange.
Watch out! Each onclick="..." must match a function name exactly, including the ().

COULD DO

You write the code
3 exercises

No code to copy. You have seen how it works — now you write it. Read the goal, write your code, and Run it. Stuck? Each one has a hint, and on the first two you can reveal a worked solution after you have had a real go.

1

Your hype button

you write it
1 Your goal
When the button is clicked, make the heading say "JavaScript is awesome!" — in a colour you like, and bigger. Write your code inside go().
2 Write your code
3 Result
<h1 id="msg">click the button</h1>
<button onclick="go()">Go</button>

<script>
  function go() {
    let m = document.getElementById("msg");
    m.innerHTML = "JavaScript is awesome!";
    m.style.color = "purple";
    m.style.fontSize = "60px";
  }
</script>
Hint Store the element once: let m = document.getElementById("msg"); then use m.innerHTML, m.style.color and m.style.fontSize.
2

Traffic light

you write it
1 Your goal
Stop turns the page background red and the heading to "STOP". Go turns it green and the heading to "GO". Write both functions.
2 Write your code
3 Result
<h1 id="t">Wait...</h1>
<button onclick="stop()">Stop</button>
<button onclick="go()">Go</button>

<script>
  function stop() {
    document.body.style.background = "red";
    document.getElementById("t").innerHTML = "STOP";
  }
  function go() {
    document.body.style.background = "green";
    document.getElementById("t").innerHTML = "GO";
  }
</script>
Hint You already did "paint the page" in Night mode and "two functions" in Like/Nah — this is those two skills together.
