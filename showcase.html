How to use this tool

    
This tool is for LIVE demonstration in front of students. Each tab covers one teaching beat: Form, Menu, Dropdown.

    
In each tab

    
    
      
  • Tick checkboxes at the bottom to add pieces to the preview.
    • 
      
  • The matching code lines appear on the right with the SAME colour as the toggle.
    • 
      
  • Students can SEE which code makes which piece - that's the whole point.
    • 
      
  • Reset clears the demo. Show all reveals everything at once.
    • 
    

    
Keyboard shortcuts

    
    
      
  • 1 / 2 / 3 — switch to Form / Menu / Dropdown tab
    • 
      
  • R — reset current tab
    • 
      
  • A — show all pieces of current tab
    • 
      
  • F — toggle Big Screen Mode (hides controls for screen-sharing)
    • 
      
  • ? — this help
    • 
    

    
Suggested lesson flow

    
    
      
  1. Start on FORM tab with just Name + Email + Submit (default).
    2. 
      
  2. Ask students: "What if I want a password too?" Then tick Password.
    3. 
      
  3. Same for Country, Subscribe. Each tick gets a "wow" reaction.
    4. 
      
  4. Switch to MENU tab. Show 3 plain links. Then click "Add CSS" - the menu transforms.
    5. 
      
  5. Switch to DROPDOWN tab. Show closed, then click "Show OPEN state".
    6. 
      
  6. Click "Put inside menu" to show the combined pattern from Section 9.
