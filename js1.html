Section 3. Variables with let

let makes a variable. Text in "quotes". Numbers without. + joins.

MUST DO

Type the code. Click Run.

<html>
<head>
    <title>Variables</title>
    <script>
        let myName = "Sam";
        alert("Hi, my name is " + myName);
    </script>
</head>

<body>
    <h1>Variables</h1>
</body>
</html>

Section 4. Ask the user with prompt()

prompt() asks the user a question.

MUST DO

Type the code. Click Run. Type your name.

<html>
<head>
    <title>Ask the user</title>
    <script>
        let userName = prompt("What is your name?");
        alert("Hello, " + userName + "!");
    </script>
</head>

<body>
    <h1>Question time</h1>
</body>
</html>

SHOULD DO

Ask 2 questions. Use both answers in one alert.

<html>
<head>
    <title>Two questions</title>
    <script>
        let userName = prompt("What is your name?");
        let userAge  = prompt("How old are you?");
        alert("Hi " + userName + "! You are "
              + userAge + " years old.");
    </script>
</head>

<body>
    <h1>Two questions</h1>
</body>
</html>

COULD DO

Ask 3 questions. console.log each answer.

let fav = prompt("Favourite colour?");
console.log("name:", userName);
console.log("age:", userAge);
console.log("colour:", fav);

Section 5. Put it all together

Combine prompt, alert and console.log.

MUST DO

Type the greeting program. Click Run.

<html>
<head>
    <title>Greeting machine</title>
    <script>
        let userName = prompt("What is your name?");
        alert("Hello, " + userName + "!");
        console.log("Greeted:", userName);
    </script>
</head>

<body>
    <h1>Greeting machine</h1>
</body>
</html>

SHOULD DO

Ask name AND favourite food. Greet with both.

<html>
<head>
    <title>Greeting v2</title>
    <script>
        let userName = prompt("What is your name?");
        let favFood = prompt("Favourite food?");
        alert("Hi " + userName + "! I love "
              + favFood + " too.");
        console.log("name:", userName);
        console.log("food:", favFood);
    </script>
</head>

<body>
    <h1>Greeting v2</h1>
</body>
</html>
