The for Loop Machine

Watch the counter. Watch the check go YES or NO. See exactly where the loop stops.

for ( let i = 1 ; i <= 5 ; i = i + 1 ) { print i }
● start — where i begins ● check — keep going while this is TRUE ● step — how i changes each time
SET i→ CHECK→ DO (print i)→ STEP (change i)
↻ after STEP it loops back to CHECK — again and again — until the check is NO.

<= INCLUDES the last number.   < STOPS just before it.
So i<=999 and i<1000 are the SAME loop — both stop at 999.
