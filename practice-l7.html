Anatomy of a list + random pick

A list holds many values; Math.random picks one. This one pattern powers colour changers, dice, Magic 8-balls and more:
let players = ["Messi", "Ronaldo", "Sam Kerr"];
let i = Math.floor(Math.random() * players.length);
msg.innerHTML = players[i];
  • [ "a", "b", "c" ] a list (array) of values, inside [ ]
  • players[0] read one item by its index — lists start at 0
  • .length how many items are in the list
  • Math.random() a random number — Math.floor(... * length) makes a random index
  • innerHTML show the picked item on the page

Dice roll + a decision

Put random + if/else together (the two halves of "a decision"). Math.random()*6 rolls 1-6, then if (n >= 4) calls it HIGH or low. This is one of your 30 June apps!

1 Read this code can’t copy – type it yourself
<h1 id="msg">Roll the dice!</h1>
<button onclick="roll()">Roll</button>

<script>
  function roll() {
    let n = Math.floor(Math.random() * 6) + 1;
    if (n >= 4) {
      document.getElementById("msg").innerHTML = n + " - HIGH!";
    } else {
      document.getElementById("msg").innerHTML = n + " - low";
    }
  }
</script>

Magic Answer

This is the capstone — a Magic 8-ball you’d actually use. A list of answers, Math.random() picks one, and innerHTML shows it. It is the SAME trick as every tile today — just a new list. Type it, press Run, then keep asking.

1 Read this code can’t copy – type it yourself
<h1 id="msg">Ask the Magic Ball!</h1>
<button onclick="ask()">Will the Socceroos win?</button>

<script>
  function ask() {
    let answers = ["YES!", "No way", "Maybe...", "Ask again", "Definitely!"];
    let pick = answers[Math.floor(Math.random() * answers.length)];
    document.getElementById("msg").innerHTML = pick;
