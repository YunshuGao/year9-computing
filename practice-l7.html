Anatomy of a Loop

A loop repeats code so you don’t write it 100 times. Here are the parts of a for loop:
for (let i = 1; i <= 5; i = i + 1) {
    blocks = blocks + "Mine! ";
}
  • for starts the loop
  • let i = 1 the start — where the counter begins
  • i <= 5 the condition — keep looping while this is true
  • i = i + 1 the step — add 1 to the counter each time
  • { } the body — the code that repeats
  • while a second kind of loop — repeat until something becomes true

Place a row of blocks

A for loop repeats code so you don’t write it 5 times. This one places one green block per loop — 5 in a row. Type it, press Run, then click Build.

  function build() {
    let row = "";

Loop a list into a scoreboard

A loop’s best friend is a list — here, TWO lists (names and scores). The loop visits each player by index and builds a ranked row. i + 1 turns the index 0, 1, 2 into ranks #1, #2, #3 — just like a real game.

  function show() {
    let names = ["Alex", "Steve", "Zoe", "Max"];

The <code>while</code> loop

A while loop repeats until something is true — perfect when you don’t know how many tries. Dig stone until you hit diamond!

1 Read this code can’t copy – type it yourself
<div id="out"></div>
<button onclick="mine()">Mine</button>

<script>
  function mine() {
    let dug = "";
    let found = false;
    while (found === false) {
      dug = dug + "<span class='blk stone'></span>";
      if (Math.random() < 0.2) {
        dug = dug + "<span class='blk diamond'></span>";
        found = true;
      }
    }
    document.getElementById("out").innerHTML = dug + "<p>Found diamond!</p>";
  }
</script>

Build your inventory

The capstone — generate a whole inventory page with ONE loop. The loop goes through your list of items and builds a slot for each. This is exactly how real websites build menus, galleries and lists. Type it, Run it, then fill your bag.

1 Read this code can’t copy – type it yourself
<h3>My hotbar</h3><div id="bag"></div>
<button onclick="fill()">Fill my hotbar</button>

<script>
  let items = ["Sword", "Pickaxe", "Torch", "Apple", "Diamond", "Bow", "Map", "Bread", "Shield"];
  function fill() {
    let bag = "";
    for (let i = 0; i < items.length; i = i + 1) {
      bag = bag + "<span class='slot'>" + items[i] + "</span>";
    }
    document.getElementById("bag").innerHTML = bag;
  }
</script>
