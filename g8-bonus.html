Section 3. Get ready for JavaScript

JavaScript needs id="..." to find things. Add ids + a <button>.

MUST DO

Add id to the text input. Change submit to <button>.

<html>
<head>
    <title>My Favourites</title>
</head>

<body>
    <h1>Tell me yours!</h1>
    <form action="" method="post">
        Your name:
        <input type="text" name="yourname" id="nameBox">
        <br><br>
        <button id="sendBtn">Send</button>
    </form>
</body>
</html>

SHOULD DO

Add ids to ALL fields. Add <p id="output"></p>.

<html>
<head>
    <title>My Favourites</title>
</head>

<body>
    <h1>Tell me yours!</h1>
    <form action="" method="post">
        Your name:
        <input type="text" name="yourname" id="nameBox">
        <br><br>

        Your message:
        <br>
        <textarea name="msg" id="msgBox"
                  rows="4" cols="40"></textarea>
        <br><br>

        How did you find this site?
        <select name="found" id="foundList">
            <option>Friend told me</option>
            <option>Google search</option>
            <option>Just exploring</option>
        </select>
        <br><br>

        Email me back?
        <input type="checkbox" name="emailme" id="emailBox">
        <br><br>

        <button id="sendBtn">Send</button>
    </form>

    <p id="output"></p>
</body>
</html>

Section 4. Style your site with CSS

Add a <style> block to <head>.

MUST DO

Add one CSS rule for background colour. Click Run.

<html>
<head>
    <title>My Favourites</title>
    <style>
        body { background-color: lightyellow; }
    </style>
</head>

<body>
    <h1>My Favourites</h1>
    <p>Welcome to my favourites page.</p>
</body>
</html>
