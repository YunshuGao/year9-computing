How to use the workshop
1. Type your name at the top.
2. Read each section. Type the blue code into the editor (you cannot copy it - that's how you learn!).
3. Click Run to see your page.
4. Tick "I finished this section" when done.
5. Write a short reflection. Your work auto-saves while you type.
6. When you've finished as much as you can, click Submit My Work. A file will download - upload it to Google Classroom.
Teacher tools. Live Code (type & run on the projector), Showcase (toggle-based visual demo), Live Demo (line-by-line code reveal), or Marking Tool. Live Code → Showcase → Live Demo → Marking Tool →
