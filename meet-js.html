4

Change the page

SHOULD DO

Popups are fine, but real apps CHANGE THE PAGE. We give an element an id, find it with document.getElementById, then change its innerHTML when a button is clicked.

► Watch & answer (2 min): Mosh changes a button on the page from JavaScript. (He uses document.querySelector — we use document.getElementById — same idea: find an element, change it.)
Answer this
Why do we add id="title" to the <h1>? What does JS use that for?
MUST DO — Copy this. Click Run, then click the button on the right. The heading should change.
1 Read this code
<!DOCTYPE html>
<html>
<body>

<h1 id="title">Hello</h1>
<button onclick="change()">Change it</button>

<script>
    function change() {
        document.getElementById("title").innerHTML = "Changed!";
    }
</script>

</body>
</html>
<!DOCTYPE html>
<html>
<body>

<h1 id="title">Click the button</h1>
<button onclick="change()">Make it red</button>

<script>
    function change() {
        document.getElementById("title").innerHTML = "WOW!";
        document.getElementById("title").style.color = "red";
    }
</script>

</body>
</html>
<!DOCTYPE html>
<html>
<body>

<h1 id="title">Hello!</h1>
<button onclick="darkMode()">Dark</button>
<button onclick="lightMode()">Light</button>

<script>
    function darkMode() {
        document.body.style.background = "black";
        document.getElementById("title").style.color = "yellow";
    }
    function lightMode() {
        document.body.style.background = "white";
        document.getElementById("title").style.color = "black";

</script>

</body>

6

Make a decision

COULD DO

JavaScript can make a choice: if something is true, do one thing; else, do another. To compare two numbers we use == (NOT a single =!).

► Watch & answer (90 sec): Mosh shows if (15 >= 16) { ... } else { ... } — the syntax rules.
Answer this
Why does JS use == to compare, not =?
MUST DO — Copy this. Click Run. The page should say “Big” because 10 is greater than 5.
1 Read this code
<!DOCTYPE html>
<html>
<body>

<h1 id="result">...</h1>

<script>
    let n = 10;
    if (n > 5) {
        document.getElementById("result").innerHTML = "Big";
    } else {
        document.getElementById("result").innerHTML = "Small";
    }
</script>

</body>
</html>
<!DOCTYPE html>
<html>
<body>

<h1 id="result">...</h1>

<script>
    let score = 7;
    if (score >= 8) {
        document.getElementById("result").innerHTML = "Top marks!";
    } else if (score >= 5) {
        document.getElementById("result").innerHTML = "Good job";
    } else {
        document.getElementById("result").innerHTML = "Keep going";
    }
</script>

</body>
</html>
<!DOCTYPE html>
<html>
<body>

<h1 id="result">Hello</h1>
<button onclick="check()">Guess my number</button>

<script>
    function check() {
        let guess = Number(prompt("Pick 1-10"));
        let secret = 7;
        if (guess == secret) {
            document.getElementById("result").innerHTML = "Got it!";
        } else if (guess < secret) {
            document.getElementById("result").innerHTML = "Too low";
        } else {
            document.getElementById("result").innerHTML = "Too high";
        }
    }
</script>

</body>
</html>
