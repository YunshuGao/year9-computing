Anatomy of a web page

Three languages on one page: HTML builds it, CSS paints it, JavaScript makes it move. Here they are side by side:
<style>
  body { background-color: #11132a; }
</style>

<h1 id="screen">NEON ARCADE</h1>
<button onclick="start()">Play</button>

<script>
  function start() {
    screen.innerHTML = "Game on!";
  }
</script>
  • HTML the structure — headings, buttons, lists
  • CSS the style — colour, background, padding, inside <style>
  • JavaScript the behaviour — what happens on a click, inside <script>
  • id the name tag — how JS finds the part to change
  • innerHTML changes the page — swaps what a part shows

Pick a random game (JS)

The magic trick: a list plus Math.random picks a different game every click. Math.floor(Math.random() * games.length) gives a random spot in the list.

1 Read this code can’t copy – type it yourself
<h2 id="out">Spin to pick a game!</h2>
<button onclick="spin()">Lucky Spin</button>

<script>
  function spin() {
    let games = ["Guess the Number", "Dice Duel", "Maze Run"];
    let i = Math.floor(Math.random() * games.length);
    document.getElementById("out").innerHTML = games[i];
  }
</script>

Guess the number (if/else)

A real mini-game. prompt asks for a guess, then if / else if / else decides: you win, too low, or too high.

1 Read this code can’t copy – type it yourself
<h2 id="out">Guess my number (1-5)</h2>
<button onclick="play()">Take a guess</button>

<script>
  function play() {
    let guess = Number(prompt("Pick 1 to 5"));
    let secret = 3;
    if (guess === secret) {
      document.getElementById("out").innerHTML = "You win!";
    } else if (guess < secret) {
      document.getElementById("out").innerHTML = "Too low";
    } else {
      document.getElementById("out").innerHTML = "Too high";
    }
  }
</script>

List the games with a loop (JS)

A for loop does the boring work. It walks the games list and builds a <p> for each one with innerHTML - one piece of code, the whole list on screen.

1 Read this code can’t copy – type it yourself
<h2>All my games</h2>
<div id="out"></div>
<button onclick="list()">Show all games</button>

<script>
  function list() {
    let games = ["Guess the Number", "Dice Duel", "Lucky Spin"];
    let html = "";
    for (let i = 0; i < games.length; i = i + 1) {
      html = html + "<p>" + games[i] + "</p>";
    }
    document.getElementById("out").innerHTML = html;
  }
</script>
