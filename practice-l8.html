Anatomy of a web page

Three languages on one page: HTML builds it, CSS paints it, JavaScript makes it move. Here they are side by side:
<style>
  body { background-color: #8fd0f5; }
</style>

<h1 id="screen">CRAFT WORLD</h1>
<button onclick="mine()">Mine</button>

<script>
  function mine() {
    screen.innerHTML = "Mined!";
  }
</script>
  • HTML the structure — headings, buttons, lists
  • CSS the style — colour, background, padding, inside <style>
  • JavaScript the behaviour — what happens on a click, inside <script>
  • id the name tag — how JS finds the part to change
  • innerHTML changes the page — swaps what a part shows

Open a random chest (JS)

The magic trick: a list plus Math.random gives a different block every click. Math.floor(Math.random() * blocks.length) picks a random spot in the list.

1 Read this code can’t copy – type it yourself
<h2 id="out">Open the chest!</h2>
<button onclick="loot()">Lucky mine</button>

<script>
  function loot() {
    let blocks = ["Diamond", "Gold", "Redstone"];
    let i = Math.floor(Math.random() * blocks.length);
    document.getElementById("out").innerHTML = "You found: " + blocks[i];

Guess the block (if/else)

A real mini-game. prompt asks which block hides the diamond, then if / else if / else decides: found it, dig right, or dig left.

1 Read this code can’t copy – type it yourself
<h2 id="out">Which block hides the diamond? (1-5)</h2>
<button onclick="dig()">Dig</button>

<script>
  function dig() {
    let guess = Number(prompt("Pick a block, 1 to 5"));
    let diamond = 3;
    if (guess === diamond) {
      document.getElementById("out").innerHTML = "Diamond found!";
    } else if (guess < diamond) {
      document.getElementById("out").innerHTML = "Dig further right";
    } else {
      document.getElementById("out").innerHTML = "Dig further left";
    }
  }
</script>

Build the inventory with a loop (JS)

A for loop does the boring work. It walks the blocks list and builds a <p> for each one with innerHTML - one piece of code, the whole inventory on screen.

1 Read this code can’t copy – type it yourself
<h2>My inventory</h2>
<div id="out"></div>
<button onclick="show()">Open inventory</button>

<script>
  function show() {
    let blocks = ["Grass", "Stone", "Diamond"];
    let html = "";
    for (let i = 0; i < blocks.length; i = i + 1) {
      html = html + "<p>" + blocks[i] + "</p>";
    }
    document.getElementById("out").innerHTML = html;
  }
</script>
