Anatomy of a web page

Three languages on one page: HTML builds it, CSS paints it, JavaScript makes it move. Here they are side by side:
<!DOCTYPE html>
<html>
<head>
  <style>
    body { background-color: skyblue; }
  </style>
</head>

<body>
  <h1 id="screen">CRAFT WORLD</h1>
  <button onclick="mine()">Mine</button>

  <script>
    function mine() {
      document.getElementById("screen").innerHTML = "Mined!";
    }
  </script>
</body>
</html>
  • HTML the structure — headings, buttons, lists
  • CSS the style — colour, background, padding, inside <style>
  • JavaScript the behaviour — what happens on a click, inside <script>
  • id the name tag — how JS finds the part to change
  • innerHTML changes the page — swaps what a part shows

Repeat with a loop (for)

A loop does the boring work for you. This for loop walks the blocks list and joins every block into one line with innerHTML — one short piece of code shows the whole inventory. Type it, then Run.

1 Read this code type it yourself – it builds the muscle
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: monospace; text-align: center; background-color: skyblue; }
    h1 { color: green; }
  </style>
</head>
<body>
  <h1>My Inventory</h1>
  <p id="out"></p>
  <script>
    let blocks = ["Grass", "Stone", "Diamond"];
    let s = "";
    for (let i = 0; i < blocks.length; i = i + 1) {
      s = s + blocks[i] + " ";
    }
    document.getElementById("out").innerHTML = s;
  </script>
</body>
</html>
