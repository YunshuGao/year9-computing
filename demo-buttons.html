The 3 lines of JavaScript that do it

<h1 id="title">Hello</h1>
<button onclick="change()">Change it</button>

<script>
  function change() {
    document.getElementById("title")
            .innerHTML = "Changed!";  ← this just ran!
  }
</script>
Every click runs the change() function — it finds the heading by its id, and changes its text. Same page. No reload.
