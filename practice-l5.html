Anatomy of a function

A function is a named box of steps you can run again and again. Here are its parts:
function greet(name) {
    document.getElementById("msg").innerHTML = "Hi " + name;
}

greet("Messi")   ← CALL it by name to run it
  • function the keyword that starts a function
  • greet the NAME — the button calls this
  • (name) the input — a parameter
  • { } the body — the steps it runs
  • greet("Messi") the CALL — writing a function isn’t enough, you must call it
