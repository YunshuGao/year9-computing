Section 1. Make a button that runs a function

Buttons run functions when clicked. Functions are named code.

MUST DO

Type the code. Click Run. Click the button.

<html>
<head>
    <title>Click the button</title>
    <script>
        function sayHi() {
            alert("Hi there!");
        }
    </script>
</head>

<body>
    <h1>Click the button</h1>
    <button onclick="sayHi()">Click me</button>
</body>
</html>

SHOULD DO

Make the function do 2 things: alert AND console.log.

<html>
<head>
    <title>Function with 2 lines</title>
    <script>
        function sayHi() {
            alert("Hi there!");
            console.log("Button clicked.");
        }
    </script>
</head>

<body>
    <h1>Click the button</h1>
    <button onclick="sayHi()">Click me</button>
</body>
</html>

COULD DO

Use a variable in the function.

function sayHi() {
    let me = "Tom";
    alert("Hi! I'm " + me + ".");
}

Section 3. Change the page (getElementById + innerHTML)

getElementById finds a part of the page. .innerHTML is its text.

MUST DO

Type the code. Click Run. Click the button.

<html>
<head>
    <title>Change the page</title>
    <script>
        function changeTitle() {
            document.getElementById("title").innerHTML
                = "You changed me!";
        }
    </script>
</head>

<body>
    <h1 id="title">Click the button</h1>
    <button onclick="changeTitle()">Change the title</button>
</body>
</html>

SHOULD DO

Change a paragraph too. Add a second button.

<html>
<head>
    <title>Change two things</title>
    <script>
        function changeTitle() {
            document.getElementById("title").innerHTML
                = "You changed me!";
        }
        function changeMsg() {
            document.getElementById("msg").innerHTML
                = "Paragraph changed!";
        }
    </script>
</head>

<body>
    <h1 id="title">Click the button</h1>
    <p id="msg">Original paragraph.</p>
    <button onclick="changeTitle()">Change title</button>
    <button onclick="changeMsg()">Change paragraph</button>
</body>
</html>

COULD DO

Add a Reset button that puts the original text back.

function reset() {
    document.getElementById("title").innerHTML
        = "Click the button";
    document.getElementById("msg").innerHTML
        = "Original paragraph.";
}
<button onclick="reset()">Reset</button>

Section 5. Put it together (ask + change the page)

Combine: function + button + prompt + DOM. The real deal.

MUST DO

Type the code. Click Run. Click Greet me.

<html>
<head>
    <title>Greet me</title>
    <script>
        function greet() {
            let name = prompt("What is your name?");
            document.getElementById("title").innerHTML
                = "Hello, " + name + "!";
        }
    </script>
</head>

<body>
    <h1 id="title">Click Greet me</h1>
    <button onclick="greet()">Greet me</button>
</body>
</html>

SHOULD DO

Ask name AND age. Put both on the page.

<html>
<head>
    <title>Greet me v2</title>
    <script>
        function greet() {
            let name = prompt("What is your name?");
            let age  = prompt("How old are you?");
            document.getElementById("title").innerHTML
                = "Hello, " + name + "!<br>"
                + "You are " + age + " years old.";
        }
    </script>
</head>

<body>
    <h1 id="title">Click Greet me</h1>
    <button onclick="greet()">Greet me</button>
</body>
</html>

COULD DO

Mini quiz: "What is 2+2?" Show Correct or Try again.

function quiz() {
    let ans = prompt("What is 2 + 2?");
    let t = document.getElementById("title");
    if (ans == "4") {
        t.innerHTML = "Correct!";
        t.style.color = "green";
    } else {
        t.innerHTML = "Try again!";
        t.style.color = "red";
    }
}
