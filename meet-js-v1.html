The CONTENT

The text, the headings, the images, the buttons themselves. Like the VIDEO file on TikTok.

🎨

CSS

The colours, the layout, the fonts, the spacing. Like the UI design of TikTok.

The ACTION

The heart-pop when you tap. The next video sliding in. The comments loading. This is what we're learning.

🚗 Think of a car:
HTML = the body of the car (the shape, the seats, the steering wheel)
CSS = the paint and the seats (how it looks)
JavaScript = the ENGINE (what makes it MOVE)

2. Magic Heading

MUST DO
What you'll make: click a button → the heading changes COLOUR.
WOW moment: you'll change the page itself, in front of your eyes. This is how Instagram, TikTok, every app works.
<html>
<body>

  <h1 id="title">My Page</h1>

  <button onclick="
    document.getElementById('title').style.color = 'red';
  ">Make it red</button>

</body>
</html>
📚 Want to know more? W3Schools: Changing CSS with JS

3. Greet Me By Name

MUST DO
What you'll make: the page asks for YOUR name, then greets you.
WOW moment: the page knows you. It REMEMBERS what you typed. That's a real program, not just a poster.
<html>
<body>

  <h1 id="title">Click the button below</h1>

  <button onclick="greetMe()">Greet me</button>

  <script>
    function greetMe() {
      let name = prompt("What is your name?");
      document.getElementById('title').innerHTML
          = "Hello " + name + "! 👋";
    }
  </script>

</body>
</html>
📚 Want to know more? W3Schools: JS Functions  ·  W3Schools: Variables (let)

4. Rainbow Page

SHOULD DO
What you'll make: 5 buttons, each turns the page a different colour.
WOW moment: you'll make the WHOLE PAGE change. Test all 5 buttons in a row — rainbow time.
<html>
<body>

  <h1>Pick a colour</h1>

  <button onclick="document.body.style.background='lightblue'">Blue</button>
  <button onclick="document.body.style.background='lightgreen'">Green</button>
  <button onclick="document.body.style.background='pink'">Pink</button>
  <button onclick="document.body.style.background='gold'">Gold</button>
  <button onclick="document.body.style.background='white'">Reset</button>

</body>
</html>
📚 Want to know more? W3Schools: JS Events (onclick and friends)

5. Mini Calculator

SHOULD DO
What you'll make: page asks for 2 numbers, then shows the sum.
WOW moment: real maths in your browser. Number() turns the typed text into a real number so 3 + 5 isn't "35".
<html>
<body>

  <h1 id="result">Click to start</h1>

  <button onclick="addThem()">Add 2 numbers</button>

  <script>
    function addThem() {
      let a = Number(prompt("First number?"));
      let b = Number(prompt("Second number?"));
      let total = a + b;
      document.getElementById('result').innerHTML
          = a + " + " + b + " = " + total;
    }
  </script>

</body>
</html>
📚 Want to know more? W3Schools: JS Operators (+ - * /)

6. Quiz Game

COULD DO
What you'll make: asks a quiz question. Says “Correct!” in green or “Try again” in red.
WOW moment: your first piece of real LOGIC. The code makes a DECISION based on what the user types. This is how every app, game and website thinks.
<html>
<body>

  <h1 id="result">Quiz!</h1>

  <button onclick="quiz()">Start the quiz</button>

  <script>
    function quiz() {
      let answer = prompt("What is 2 + 2?");
      let result = document.getElementById('result');

      if (answer == "4") {
        result.innerHTML = "Correct! 🎉";
        result.style.color = "green";
      } else {
        result.innerHTML = "Try again";
        result.style.color = "red";
      }
    }
  </script>

</body>
</html>
📚 Want to know more? W3Schools: JS If/Else (logic)  ·  W3Schools: Comparisons (==, >, <)
