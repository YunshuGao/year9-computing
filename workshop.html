Colours & CSS

COULD DO

Real designers build with colour systems, not random reds. Try a coordinated theme, an image background, and a dark mode.

Style 4 elements with a coordinated colour theme (body / h1 / h2 / p / a).
1 Read this code

    <title>Colour Theme</title>
    <style>
        body {
            background-color: #f0f4ff;
            color: #1f2937;

7

Fonts & Borders

COULD DO

Three design exercises. Pair fonts. Build a card. Make a callout box. These are the building blocks of modern web design.

Use TWO different fonts: one for headings, another for body text.
1 Read this code
<html>
<head>
    <title>Two Fonts</title>
    <style>
        body {
            font-family: Georgia, serif;
            font-size: 17px;
            line-height: 1.6;
        }
        h1, h2 {
            font-family: "Arial Black", sans-serif;
            letter-spacing: 1px;
        }
    </style>
</head>
<body>
    <h1>Magazine Style</h1>
    <h2>A neat headline</h2>
    <p>The body uses a serif font (Georgia).
       Headings use a sans-serif font
       (Arial Black). Two fonts = visual rhythm.</p>
</body>
</html>
<style>
    body {
        font-family: Arial, sans-serif;
        background: #f4f6fb;
        padding: 20px;
    }
    .card {
        border: 2px solid #1f3a68;
        border-radius: 12px;
        padding: 20px 24px;
        margin: 16px 0;
        max-width: 320px;
        background-color: white;
    }
    .card h2 {
        margin-top: 0;
        color: #1f3a68;
    }
</style>

<div class="card">
    <h2>My Card</h2>
    <p>Cards are everywhere.
       Twitter posts, Instagram, news sites.
       All cards.</p>
</div>
<style>
    body {
        font-family: Arial;
        padding: 20px;
    }
    .note {
        border-left: 5px solid #f59e0b;
        background: #fffbeb;
        padding: 14px 18px;
        margin: 16px 0;
        border-radius: 4px;
    }
    .note h3 {
        margin: 0 0 6px 0;
        color: #92400e;
    }
    .note p {
        margin: 0;
        color: #78350f;
    }
</style>

<div class="note">
    <h3>Important note</h3>
    <p>Remember to submit your work
       before the bell.</p>
</div>
