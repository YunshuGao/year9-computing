Multi-page Menu

COULD DO

Real websites have many pages linked by a menu. Use <nav> + <a href> links. The same menu appears on every page.

Build a basic nav menu with 3 links: Home, About, Contact.
1 Read this code
<html>
<head>
    <title>Home</title>
</head>
<body>
    <nav>
        <a href="index.html">Home</a> |
        <a href="about.html">About</a> |
        <a href="contact.html">Contact</a>
    </nav>
    <hr>

    <h1>Welcome</h1>
    <p>Click the menu above to look around.</p>
</body>
</html>
<style>
    body {
        font-family: Arial;
        margin: 0;
    }
    nav {
        background: navy;
        padding: 14px 22px;
    }
    nav a {
        color: white;
        text-decoration: none;
        padding: 6px 14px;
        font-weight: bold;
    }
    nav a:hover {
        background: orange;
        border-radius: 4px;
    }
    h1, p { padding: 0 22px; }
</style>

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="contact.html">Contact</a>
</nav>

<h1>Welcome</h1>
<p>A styled menu.</p>

7

Dropdown Menu

★ TODAY COULD DO

A dropdown shows or hides content when clicked. Just two tags: <details> wraps it, <summary> is what you click. No JavaScript needed.

Build a basic dropdown using
and .
1 Read this code
<h1>Help</h1>

<details>
    <summary>Click to open</summary>
    <p>This is the hidden content.
       It only shows when you click
       the summary above.</p>
</details>
<h1>Frequently Asked Questions</h1>

<details>
    <summary>How do I sign up?</summary>
    <p>Fill in the form. Click Send.</p>
</details>

<details>
    <summary>Is my data safe?</summary>
    <p>Yes - we never share it.</p>
</details>

<details>
    <summary>Where do answers go?</summary>
    <p>To the website owner.</p>
</details>
<nav>
    <a href="#">Home</a>

    <details>
        <summary>Photos</summary>
        <ul>
            <li><a href="#">Sport</a></li>
            <li><a href="#">School</a></li>
            <li><a href="#">Family</a></li>
        </ul>
    </details>

    <a href="#">Contact</a>
</nav>
