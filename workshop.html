Your First Web Page

MUST DO

Every web page is built from tags. A tag looks like <h1>. Tags come in pairs: an opening tag and a closing tag. Today you will build your first page.

Editor — type here
Result — your page appears here
1 Step 1 — Type this exactly

Type this in the editor. Click Run to see your page.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>All About Me</title>
</head>
<body>
    <h1>All About Me</h1>
    <p>Hi! My name is _____. I am in Year 9.</p>
</body>
</html>
2 Step 2 — Make it about you

Replace _____ with your real name. Add a second paragraph about something you like.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>All About Me</title>
</head>
<body>
    <h1>All About Me</h1>
    <p>Hi! My name is Sam. I am in Year 9.</p>
    <p>I love playing basketball after school.</p>
</body>
</html>
3 Step 3 — Try the challenge

Make one word bold using <strong> and one word italic using <em>.

<p>I love playing <strong>basketball</strong> after school.</p>
<p>My favourite team is the <em>Sydney Kings</em>.</p>

2

Headings & Paragraphs

MUST DO

Headings break your page into parts. The biggest heading is <h1>. The next size down is <h2>, then <h3>. There are 6 sizes (h1 to h6).

Editor — type here
Result — your page
1 Step 1 — Three headings

Type this code. Notice how each heading is a different size.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>My Second Page</title>
</head>
<body>
    <h1>My Second Web Page</h1>

    <h2>What this is</h2>
    <p>A page built with HTML.</p>

    <h2>Why I'm doing this</h2>
    <p>To learn how websites work.</p>
</body>
</html>
2 Step 2 — Add a third topic

Add a third <h2> called About my school with a paragraph under it.

<h2>About my school</h2>
<p>I go to high school in Parramatta.</p>
3 Step 3 — Use a sub-heading (h3)

Pick one of your <h2> topics. Add an <h3> sub-heading under it.

<h2>About my school</h2>
<p>I go to high school.</p>

<h3>My favourite subject</h3>
<p>I really like Computing because we build websites.</p>

3

Lists & Links

MUST DO

Lists are great for showing items. A bullet list uses <ul> (unordered list). A numbered list uses <ol> (ordered list). Each item goes in <li>. A link uses <a href="...">.

Editor
Result
1 Step 1 — A bullet list

Build a bullet list of 3 things you like.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>Things I Like</title>
</head>
<body>
    <h1>Things I Like</h1>
    <ul>
        <li>Basketball</li>
        <li>Pizza</li>
        <li>Music</li>
    </ul>
</body>
</html>
2 Step 2 — A numbered list

Add a numbered list of your top 5 things. Use <ol> instead of <ul>.

<h2>My top 5</h2>
<ol>
    <li>First favourite</li>
    <li>Second favourite</li>
    <li>Third favourite</li>
    <li>Fourth favourite</li>
    <li>Fifth favourite</li>
</ol>
3 Step 3 — Add a link

Add a link to a website you like. The tag is <a href="...">text</a>.

<p>Watch matches at
   <a href="https://www.nba.com">NBA.com</a>
</p>

4

Forms — let people type in

MUST DO

Forms let people fill in their details on your website. We won't process the answers (that needs JavaScript later) — today we will build the form. A form starts with <form> and uses <input> tags for each box.

Editor
Result
1 Step 1 — A simple form

Build a form with one name box and a Submit button.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>Sign Up</title>
</head>
<body>
    <h1>Sign Up</h1>
    <form>
        <label>Name:
            <input type="text" name="name">
        </label>
        <br><br>
        <input type="submit" value="Submit">
    </form>
</body>
</html>
2 Step 2 — More input types

Add email, password, and a big message box (<textarea>).

<form>
    <label>Name:
        <input type="text" name="name">
    </label><br><br>

    <label>Email:
        <input type="email" name="email">
    </label><br><br>

    <label>Password:
        <input type="password" name="pw">
    </label><br><br>

    <label>Your message:<br>
        <textarea name="msg" rows="4" cols="40"></textarea>
    </label><br><br>

    <input type="submit" value="Send">
</form>
3 Step 3 — Dropdown + checkbox

Add a <select> dropdown for favourite subject and a checkbox to subscribe.

<label>Favourite subject:
    <select name="subject">
        <option>Computing</option>
        <option>Maths</option>
        <option>PE</option>
        <option>Art</option>
    </select>
</label><br><br>

<label>
    <input type="checkbox" name="news">
    Send me updates
</label>

Tables — rows and columns

MUST DO

Tables show information in rows and columns. Think of a timetable or a list of scores. <table> wraps the whole table. <tr> is a row. <td> is a cell. <th> is a heading cell.

Editor
Result
1 Step 1 — A 2-row table

Build a table with 2 rows and 2 columns. Add border="1" so you can see the cells.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>My Table</title>
</head>
<body>
    <h1>My First Table</h1>
    <table border="1">
        <tr>
            <td>Apple</td>
            <td>Red</td>
        </tr>
        <tr>
            <td>Banana</td>
            <td>Yellow</td>
        </tr>
    </table>
</body>
</html>
2 Step 2 — Add a heading row

Add a heading row using <th>. <th> cells are bold and centred.

<table border="1">
    <tr>
        <th>Fruit</th>
        <th>Colour</th>
    </tr>
    <tr>
        <td>Apple</td>
        <td>Red</td>
    </tr>
    <tr>
        <td>Banana</td>
        <td>Yellow</td>
    </tr>
</table>
3 Step 3 — Build a school timetable

Build a table with 4 columns: Period, Subject, Room, Teacher. Add 3 rows of your real timetable.

<table border="1">
    <tr>
        <th>Period</th>
        <th>Subject</th>
        <th>Room</th>
        <th>Teacher</th>
    </tr>
    <tr>
        <td>1</td>
        <td>Computing</td>
        <td>12</td>
        <td>Ms Lee</td>
    </tr>
    <tr>
        <td>2</td>
        <td>Maths</td>
        <td>8</td>
        <td>Mr Smith</td>
    </tr>
    <tr>
        <td>3</td>
        <td>PE</td>
        <td>Hall</td>
        <td>Ms Jones</td>
    </tr>
</table>

6

Colours & CSS

COULD DO

CSS is how you make your page look good. CSS goes inside a <style> tag in your <head>. Each rule has a selector (which tag to style), a property (what to change), and a value (what to change it to).

Editor
Result
1 Step 1 — Colour the text

Make all paragraphs red. The selector p picks every <p> on the page.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>Colours</title>
    <style>
        p {
            color: red;
        }
    </style>
</head>
<body>
    <h1>Colour Test</h1>
    <p>This paragraph should be red.</p>
    <p>This one too!</p>
</body>
</html>
2 Step 2 — Change the background

Make the whole page background light yellow. Try other colours: lightblue, pink, aqua.

<style>
    body {
        background-color: lightyellow;
    }
    p {
        color: navy;
    }
    h1 {
        color: darkred;
    }
</style>
3 Step 3 — Style links and headings differently

Make <a> links one colour, <h1> another colour, and <h2> a third colour.

<style>
    body { background-color: #f0f4ff; }
    h1   { color: darkblue; }
    h2   { color: teal; }
    p    { color: #333; }
    a    { color: orange; }
</style>

7

Fonts & Borders

COULD DO

Change how text looks with font-family and font-size. Put a box around things with border. A border has 3 parts: width (thick or thin), style (solid, dashed, dotted), and colour.

Editor
Result
1 Step 1 — Pick a font and size

Change the font for the whole page. Make paragraphs 18 pixels tall.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>Fonts</title>
    <style>
        body {
            font-family: "Arial", sans-serif;
        }
        p {
            font-size: 18px;
        }
    </style>
</head>
<body>
    <h1>Big and Clear</h1>
    <p>This text is 18 pixels tall.</p>
</body>
</html>
2 Step 2 — Add a border

Put a blue border around your <h1>. Add some padding so the text isn't touching the edge.

<style>
    body { font-family: "Arial", sans-serif; }
    h1 {
        border: 3px solid blue;
        padding: 10px;
        color: blue;
    }
    p {
        border: 1px dashed grey;
        padding: 6px;
    }
</style>
3 Step 3 — Make a "card"

Make a paragraph look like a card: a border, padding, a background colour, and rounded corners with border-radius.

<style>
    body { font-family: "Arial", sans-serif;
           background: #f0f4ff; }
    .card {
        border: 2px solid #1f3a68;
        background: white;
        padding: 16px 20px;
        border-radius: 12px;
        max-width: 360px;
    }
</style>
...
<p class="card">
    This paragraph is a card!
</p>

8

Multi-page Site with a Menu

SHOULD DO

Real websites have many pages. Pages are linked together with a menu. The menu is just a list of <a> links. You put the same menu on every page, so users can jump between pages.

Editor
Result
1 Step 1 — A menu of 3 links

Build a Home page with a menu linking to about.html and contact.html.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>Home</title>
</head>
<body>
    <nav>
        <a href="index.html">Home</a> |
        <a href="about.html">About</a> |
        <a href="contact.html">Contact</a>
    </nav>
    <hr>
    <h1>Welcome to My Site</h1>
    <p>Hi! Use the menu at the top to look around.</p>
</body>
</html>
2 Step 2 — Style the menu

Make the menu look like a real navigation bar.

<style>
    body { font-family: Arial, sans-serif; margin: 0; }
    nav {
        background: #1f3a68;
        padding: 12px 20px;
    }
    nav a {
        color: white;
        text-decoration: none;
        padding: 6px 14px;
        font-weight: bold;
    }
    nav a:hover { background: #14b8a6;
                  border-radius: 4px; }
    h1, p { padding: 0 20px; }
</style>
3 Step 3 — Add a footer

Add a <footer> at the bottom with your name and the year.

<footer>
    <hr>
    <p style="text-align:center; color:grey;">
        (c) 2026 by Your Name
    </p>
</footer>

10

Add Images to Your Page

SHOULD DO

Images make a page interesting. Use the <img> tag. It needs two things: src (where the image is) and alt (what the image shows, for people who can't see it). The alt is not optional — it's how screen readers and search engines understand your image.

Editor
Result
1 Step 1 — One image with alt text

Use an online image and the alt attribute.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>My Photos</title>
</head>
<body>
    <h1>My Photos</h1>
    <img src="https://picsum.photos/id/237/300/200"
         alt="A black puppy looking at the camera">
</body>
</html>
2 Step 2 — Set width and height

Control the size with width and height (in pixels). Add 2 more images.

<img src="https://picsum.photos/id/237/600/400"
     alt="A black puppy"
     width="240" height="160">

<img src="https://picsum.photos/id/1015/600/400"
     alt="A mountain river"
     width="240" height="160">

<img src="https://picsum.photos/id/1025/600/400"
     alt="A pug face close-up"
     width="240" height="160">
3 Step 3 — Style images with CSS

Use CSS to add rounded corners and a border. Put a caption under each image.

<style>
    body { font-family: Arial, sans-serif; }
    img {
        border-radius: 12px;
        border: 3px solid #1f3a68;
        margin: 8px;
    }
    figcaption {
        font-style: italic;
        color: #555;
        text-align: center;
    }
</style>
...
<figure>
    <img src="https://picsum.photos/id/237/300/200"
         alt="Black puppy"
         width="280">
    <figcaption>My imaginary puppy</figcaption>
</figure>

11

Mini-Site Challenge

SHOULD DO

The big one. Use everything you've learnt to build a one-page mini-site. This is practice for your real GTPA project — if you can do this, you can do the project. Aim for one page that contains all the building blocks. Don't worry if it looks rough — the goal is to use each thing once.

Editor
Result
1 Step 1 — Build the skeleton

Start with a heading, a paragraph, a nav menu and a footer.

<!DOCTYPE html>
<html lang="en-AU">
<head>
    <meta charset="UTF-8">
    <title>My Mini-Site</title>
</head>
<body>
    <nav>
        <a href="#about">About</a> |
        <a href="#stuff">Stuff I Like</a> |
        <a href="#contact">Contact</a>
    </nav>

    <h1>My Mini-Site</h1>
    <p>Welcome! I built this in Computing class.</p>

    <footer>
        <p>(c) 2026 Your Name</p>
    </footer>
</body>
</html>
2 Step 2 — Add image, list, table, form

Now add the content blocks: an image, a list, a small table, and a contact form.

<h2 id="about">About Me</h2>
<img src="https://picsum.photos/id/1025/300/200"
     alt="A friendly dog"
     width="240">
<p>A short paragraph about who you are.</p>

<h2 id="stuff">Stuff I Like</h2>
<ul>
    <li>Music</li>
    <li>Sport</li>
    <li>Coding</li>
</ul>

<h2>This Week</h2>
<table border="1">
    <tr>
        <th>Day</th>
        <th>Plan</th>
    </tr>
    <tr>
        <td>Mon</td>
        <td>Coding</td>
    </tr>
    <tr>
        <td>Tue</td>
        <td>Basketball</td>
    </tr>
</table>

<h2 id="contact">Contact</h2>
<form>
    <label>Name:
        <input type="text" name="name">
    </label><br><br>
    <label>Message:<br>
        <textarea rows="3" cols="30"></textarea>
    </label><br><br>
    <input type="submit" value="Send">
</form>
3 Step 3 — Style it your way

Add a <style> block. Use your colours from your plan (Section 9). Make it yours!

<style>
    body {
        font-family: "Segoe UI", Arial, sans-serif;
        max-width: 760px;
        margin: 0 auto;
        padding: 20px;
        background: #f4f6fb;
        color: #1f2937;
    }
    nav {
        background: #1f3a68;
        padding: 10px 18px;
        border-radius: 8px;
    }
    nav a {
        color: white;
        text-decoration: none;
        font-weight: bold;
        padding: 4px 10px;
    }
    nav a:hover { color: #14b8a6; }
    h1 { color: #1f3a68; }
    h2 {
        color: #14b8a6;
        border-bottom: 2px solid #14b8a6;
        padding-bottom: 4px;
    }
    img { border-radius: 8px; }
    table {
        border-collapse: collapse;
        margin: 10px 0;
    }
    th, td { padding: 6px 14px; }
    th { background: #eef2ff; }
    form {
        background: white;
        padding: 14px;
        border-radius: 8px;
        border: 1px solid #e5e7eb;
        max-width: 400px;
    }
    footer {
        margin-top: 30px;
        color: #6b7280;
        font-size: 12px;
        text-align: center;
    }
</style>

Checklist for full marks: heading (h1+h2), paragraph, nav menu, image with alt, bullet list, table with th, form with input + textarea + submit, CSS styling, footer.
