Keyboard Shortcuts

  • Space or → — Next line
  • ← — Previous line
  • Enter — Next step
  • Shift + Enter — Previous step
  • R — Reset current step
  • A — Show all lines
  • ? — This help

How to use this tool in class

  • Open this page on the projector before students arrive.
  • Click a step button at the top, then press Space to reveal each line.
  • Pause after each line - read it out, point to what changes in the preview.
  • If you make a mistake, hit R to reset just the current step.
  • The code editor IS editable - you can type extra examples live.
