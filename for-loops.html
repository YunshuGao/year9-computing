🔁 How a FOR LOOP works

A loop does the same little jobs again and again. Let's go one step at a time — counting up ⬆ and down ⬇.

A loop has 4 little jobs
🏁
START  — where the number i begins (happens once)
✅
CHECK  — is i still allowed? YES = go, NO = stop
🖨️
DO  — print i (say the number out loud)
👣
STEP  — change i (+1 to go up, −1 to go down)
Do CHECK → DO → STEP  again and again.  When CHECK says NO, STOP. 🛑
⬆ Counting UP  (1, 2, 3, 4, 5)
for
(
i = 1START
;
i ≤ 5CHECK
;
i = i + 1STEP
)
→
print(i)DO

⬆ vs ⬇ — the ONLY difference
⬆ UP
start LOW (1) · check i ≤ stop · step +1
⬇ DOWN
start HIGH (5) · check i ≥ stop · step −1
Everything else is exactly the same machine. ✅
⭐ Golden rule: the loop PRINTS first, THEN changes i. So the first number that comes out is always where you START.
