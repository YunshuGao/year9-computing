Build the Compliment Generator

Three languages combine into one file. Add them one layer at a time — then click for a random compliment.

HTML — structure (heading + button)
CSS — style (in <style>, inside <head>)
JavaScript — behaviour (in <script>)
THE ONE FILE  ·  compliment.html
<!DOCTYPE html>
<html>
<head>
  <!-- the CSS style will go here -->  <style>
    body { text-align: center; font-family: Arial; }
    h1   { color: #3f3399; }
  </style>
</head>
<body>
  <h1 id="msg">Click for a compliment!</h1>
  <button onclick="compliment()">Compliment me</button>
  <!-- the JavaScript will go here -->  <script>
    function compliment() {
      let lines = ["You're a legend!", "Brilliant!", "Future developer!"];
      let pick = lines[Math.floor(Math.random() * lines.length)];
      document.getElementById("msg").innerHTML = pick;
    }
  </script>
</body>
</html>
