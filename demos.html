⚽ Function demos

Show on the board

Three quick demos for the lesson. Click the buttons live - the students watch the function run.

1 · Write + call a function

A function is a named block of code. The button CALLS it by name. Click it as many times as you like.

function kickOff() {
    // the page commentates
    out1.innerHTML = "And we're under way!";
}
Press the button →
Click again - it runs again (that's the point of a function).

2 · A function with INPUT (a parameter)

Put a word in the brackets - a parameter. Call chant("Messi") and "Messi" fills the blank.

function chant(name) {
    out2.innerHTML = name + "! " + name + "!";
}
Pick a player →
Same function, different input, different chant.

3 · Build a player card

TWO inputs - a name and a rating. One function builds the whole card. This is what they build today.

function card(name, rating) {
    // builds the gold card from the inputs
}

card("You", 99);
Change the name and the rating - it's yours.
