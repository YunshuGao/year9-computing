Show on the board

The code on the left is exactly what runs on the right. Click the buttons live.

1 · Write + call a function

A function is a named block of code. The button CALLS it - click again and it runs again (the next line of commentary).

let lines = ["And we're under way!",
             "Great pass...",
             "He shoots...",
             "GOOOAL!"];
let i = 0;

function kickOff() {
    out1.innerHTML = lines[i];
    i = (i + 1) % lines.length;
}
Press the button →
Each click runs kickOff() again - the next moment of commentary.

2 · A function with INPUT (a parameter)

Put a word in the brackets - a parameter. Call chant("Messi") and "Messi" fills the blank.

function chant(name) {
    out2.innerHTML = name + "! " + name + "!";
}
Pick a player →
Same function, different input, different chant.

3 · Build a player card

TWO inputs - a name and a rating. One function builds the whole card from them.

function card(name, rating) {
    out3.innerHTML =
      "<div class='fut'>" +
      "<div class='rt'>" + rating + "</div>" +
      "<div class='pic'></div>" +
      "<div class='nm'>" + name + "</div>" +
      "</div>";
}
Change the name and the rating - it's yours.
