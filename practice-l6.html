Anatomy of if / else

if/else lets the computer decide — run different code depending on a condition. Here are its parts:
if (australia > usa) {
    msg.innerHTML = "AUSTRALIA WINS!";
} else {
    msg.innerHTML = "Not this time!";
}
  • if starts the decision
  • (australia > usa) the condition — a true/false question
  • { } the block that runs when it is true
  • else otherwise — runs when the condition is false
  • > < >= === the ref’s questions — ways to compare two values

Penalty shootout

This is the capstone — a game you’d actually play. Math.random() gives a number from 0 to 1; the if turns it into a GOAL or a SAVE, and the score counts up. Type it, press Run, then keep shooting.

1 Read this code can’t copy – type it yourself
<h1 id="msg">Penalty shootout!</h1>
<p id="score">Goals: 0</p>
<button onclick="shoot()">Shoot!</button>

<script>
  let goals = 0;
  function shoot() {
    if (Math.random() < 0.5) {
      document.getElementById("msg").innerHTML = "GOAL!";
      goals = goals + 1;
    } else {
      document.getElementById("msg").innerHTML = "SAVED!";
    }
    document.getElementById("score").innerHTML = "Goals: " + goals;
  }
</script>
